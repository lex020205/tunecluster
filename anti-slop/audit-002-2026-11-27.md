# TuneCluster Recommendation UI Audit

Date: 2026-11-27
Mode: AFTER
Scope: Static audit of the recommendation cards and playback flow. No application source was changed.

## Findings

1. **[HIGH] R-26: “Putar” does not start audio.** The handler only stores the selected track in session state, then renders a Spotify iframe. Playback still requires the user to press Play inside that iframe, so the button's label promises more than its action performs. See [`pages/2_🎵_Rekomendasi.py`](../pages/2_🎵_Rekomendasi.py#L627) and [`utils/spotify_embed.py`](../utils/spotify_embed.py#L259).

## Technical diagnosis

- The recommender loads [`data/katalog_lagu.csv`](../data/katalog_lagu.csv), which has no artwork URL column. The original Spotify CSV also has `album_name` but no artwork URL.
- [`get_spotify_cover_url`](../utils/spotify_embed.py#L46) looks up Spotify oEmbed data and accepts only `i.scdn.co` as the thumbnail host. A live response for valid catalog track `5SuOikwiRyPMVoIQDJUgSV` returned `https://image-cdn-ak.spotifycdn.com/...`; the helper rejected it and returned `None`. [`render_track_card`](../utils/spotify_embed.py#L195) then renders “Sampul tidak tersedia”. The `None` result is cached for 24 hours.

## Approval

No fixes were applied. The finding is awaiting the user's decision.
