# TuneCluster UI Audit

Date: 2026-11-26
Mode: AFTER
Scope: Static review of the existing Streamlit UI and shared styles. No browser click-through was performed.

Design Read: Reading this as TuneCluster, a music recommender for Spotify-catalog listeners, using the existing dark interface and green primary accent. The current source suggests ENERGY 2 / RHYTHM 2 / MOTION 1.

## Findings

1. **[HIGH] R-39: Reduced-motion preferences are not respected.** [`utils/auth.py`](../utils/auth.py#L31) defines the `tuneFadeIn` animation and applies it to the main content and bordered containers at lines 62 and 78. No `prefers-reduced-motion: reduce` override exists in the reviewed UI styles, so the non-essential animation still runs for users who request reduced motion. Add a reduced-motion rule that disables these animations, then verify it in the browser.

## Approval

Finding 1 was approved and fixed in [`utils/auth.py`](../utils/auth.py). The shared stylesheet now disables animations and transitions when `prefers-reduced-motion: reduce` is active.

Validation:

- Pylance reported no syntax errors in `utils/auth.py`.
